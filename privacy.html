Madness Uploader: Privacy Policy

Effective date: 18 November 2026

Madness Uploader is a private tool that the owner of the Madness YouTube channel (youtube.com/@Madness_BH) uses to upload their own videos to their own channel. It is not offered to the public, and nobody else signs in to it.

What the tool accesses

When the channel owner signs in with Google, the tool asks for two YouTube permissions:

  • Manage your YouTube videos (youtube.upload): to upload video files to the channel.
  • See, edit and delete your YouTube videos, ratings, comments and captions (youtube.force-ssl): to set a video's thumbnail and upload its caption file.

The tool only acts on the owner's own channel and the files the owner chooses to upload. It does not read comments, ratings, subscriber lists, watch history or any other account data.

What is stored, and where

The tool keeps one sign-in token (an OAuth refresh token) on the owner's own computer, so uploads can run without signing in every time. Nothing is stored on any server run by the tool, because there isn't one. Video files, thumbnails and captions go straight from the owner's computer to YouTube.

Sharing

No data from YouTube or Google is sold, shared with third parties, used for advertising, or used to train AI models. The tool sends data only to Google's own YouTube and sign-in services.

Keeping and deleting data

The sign-in token stays on the owner's computer until it is deleted or access is revoked. The owner can revoke access at any time at myaccount.google.com/permissions, which stops the token working immediately. Deleting the token file removes the only stored copy.

Google and YouTube terms

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Madness Uploader's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
